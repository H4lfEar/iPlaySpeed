# iPlaySpeed

여러 게임의 일일 숙제를 한 화면에서 추적하고, 다음에 켤 게임을 버튼 하나로 실행해주는 멀티 게임 런처.

> 코드를 처음 다뤄 보는 분도 따라올 수 있도록 적었습니다. 막히면 그 줄을 그대로 복사해서 물어보세요.

---

## 1. 실행 방법 (3단계)

### ① .NET 8 SDK 설치 (한 번만)
https://dotnet.microsoft.com/download/dotnet/8.0 에서 **".NET 8 SDK" (Windows x64 Installer)** 를 받아 설치합니다.
(SDK라고 적힌 것을 받으세요. Runtime이 아닙니다.)

### ② 빌드 + 실행
이 폴더의 **`빌드_및_실행.bat`** 을 더블클릭하면:
1. 핵심 로직 검증 테스트가 먼저 돌고(통과해야 진행),
2. 앱이 빌드되어 실행됩니다.

> 또는 Visual Studio가 있으면 `iPlaySpeed.sln` 을 열고 F5.

### ③ 사용
1. **＋ 게임 등록** → 게임(또는 런처)의 `.exe` 선택 → 이름·아이콘 자동 등록.
2. **오버레이 표시/숨김** → 항상 위에 뜨는 게이지바. 드래그로 이동, 단축키(기본 `Ctrl+Alt+I`)로 토글.
3. 게임을 플레이하면 **게임 창이 맨 앞에 있던 시간**이 쌓여 일정 시간(기본 5분) 넘으면 완료.
4. **▶ 다음 게임** → 현재 게임을 닫고 다음 순번 게임 실행.

## 2. 지금 구현된 기능 (MVP)

| 기능 | 상태 |
|---|---|
| 게임 등록 (이름·아이콘 자동 수집) | ✅ |
| 항상 위 오버레이 게이지바 + 체크포인트 아이콘 + 드래그 이동 | ✅ |
| 게임 창 포그라운드 시간 누적으로 완료 판정 | ✅ |
| **업데이트 오판정 방지** (업데이트만 하면 미완료로 표시) | ✅ |
| 다음 게임 빠른 실행 (현재 종료 → 다음 실행) | ✅ |
| 전역 단축키 (오버레이 토글 / 다음 게임) | ✅ |
| 설정 시각 기준 진행도 자동 리셋 | ✅ |
| 패치 자동 학습/예측 기반 정렬 (관측 기반, 수동 입력 불필요) | ✅ (관측이 쌓일수록 정확) |
| 수동 완료/미완료 토글 (오판정 대비) | ✅ |

### 2차 추가된 기능
- **설치된 게임 자동 감지**: 처음 켜면 레지스트리·Steam을 훑어 내 PC의 게임을 왼쪽에 보여줌. **리스캔** 버튼으로 다시 검색.
- **드래그 앤 드롭 등록**: 왼쪽(감지) → 오른쪽(등록)으로 끌어다 놓으면 오버레이에 추가. '추가 ▶' 버튼도 가능.
- **정렬**: '업데이트 주기로 자동 정렬' 체크박스. 끄면 ▲▼로 직접 순서 변경(메인·오버레이·"다음 게임" 모두 이 순서를 공유).
- **"다음 게임" 수정**: 이제 패치 예측이 아니라 **화면에 보이는 정렬 순서**대로 다음 게임을 실행.
- **게임별 완료 임계 시간**: 각 게임 행의 "분" 칸에서 따로 설정.
- **멀티미디어 컨트롤**: 오버레이의 ⏮⏯⏭ 가 SMTC로 동작. 현재 곡/영상 **제목 표시 + 길면 좌측 스크롤(마퀴)**.

### 아직 안 된 것 (다음 단계)
- 게임/미디어 **볼륨 분리** 슬라이더 (재생 컨트롤은 됨, 볼륨은 미구현)
- 일일 소요 시간 **리더보드 화면** (기록은 `history.json`에 저장 중)
- 런처 '플레이' 버튼 **자동 클릭** (설정에 안전 토글만 준비, 실제 클릭 동작은 미구현)

> 빌드 환경(인코딩): `Directory.Build.props`가 모든 소스를 UTF-8로 읽도록 지정해, 한글 문자열이 깨지지 않습니다.
> 미디어 컨트롤은 Windows 10 SDK(자동 복원)를 쓰므로 첫 빌드 시 패키지 복원에 시간이 조금 더 걸릴 수 있습니다.

## 3. 검증 상태 (중요)

- **핵심 로직(완료 판정·업데이트 보정·패치 예측·일일 리셋)** 은 알고리즘을 먼저 Python으로 구현해 **28개 테스트로 검증**했고, 같은 시나리오를 C# 단위 테스트(`src/IPlaySpeed.Core.Tests`)로 옮겨 두었습니다. `빌드_및_실행.bat` 이 이 테스트를 매번 먼저 돌립니다.
- **UI(WPF) 부분** 은 Windows 전용이라 제작 환경에서 직접 실행 확인은 못 했고, 코드 리뷰로 검토했습니다. 처음 빌드 시 사소한 조정이 필요할 수 있으며, 오류 메시지가 나오면 그대로 알려주시면 바로 고쳐 드립니다.

## 4. 폴더 구조

```
iPlaySpeed/
├─ iPlaySpeed.sln
├─ 빌드_및_실행.bat
├─ design.md                    ← 구현 핸드오프 (에이전트 1순위)
├─ .cursor/rules/iPlaySpeed.md  ← Cursor 규칙
├─ tasks/iPlaySpeed/             ← lessons, HANDOFF, PhaseOverview (gitignore)
└─ src/ ...
```

데이터는 `%AppData%\iPlaySpeed\` 에 JSON으로 저장됩니다 (`games.json`, `states.json`, `patches.json`, `settings.json`, `history.json`).

## 5. 알아두면 좋은 점

- **전체화면 독점 모드**에서는 오버레이가 보이지 않습니다. 게임을 **'테두리 없는 창모드'** 로 두세요.
- 게임 종료가 권한 문제로 막히면, `iPlaySpeed.exe` 를 **관리자 권한으로 실행**해 보세요.
- **런처 자동 클릭은 약관 위반·계정 정지 위험**이 있어 기본 꺼짐이며, 자동 로그인/비밀번호 입력은 하지 않습니다.
